# Grafiche dell'arena di Racchetta

Loghi, scritte e schermi dell'arena (Nitto ATP Finals, ESPORTS FITP, «It all adds up to THIS», TORINO), ritagliati
dalle immagini di riferimento dell'arena fornite da FITP eSports (ottobre 2026), per riprodurre fedelmente il campo.
Marchi dei rispettivi titolari, usati per il progetto FITP eSports. Per una resa più nitida si possono sostituire
con i file ufficiali (vettoriali o PNG ad alta risoluzione) mantenendo gli stessi nomi: il codice non cambia.
