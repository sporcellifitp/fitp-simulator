# Grafiche dell'arena di Racchetta

Loghi, scritte e schermi dell'arena (Nitto ATP Finals, ESPORTS FITP, «It all adds up to THIS» con la coppa, TORINO).
Tutti i supporti con i loghi sono generati dai file ufficiali vettoriali (logo orizzontale Nitto ATP Finals per fondi
scuri, ESPORTS FITP negativo; la versione impilata è composta con i blocchi del logo ufficiale) con `natpf-tennis/scripts/brand/brand-assets.py`, ad alta risoluzione e con le proporzioni dei pannelli 3D
di `site/js/tennis/arena.js` (i loghi non si deformano). I loghi ritagliati per l'interfaccia stanno in
`site/assets/brand/`. `torino.png` resta quella ricavata dalle immagini di riferimento. Marchi dei rispettivi titolari,
usati per il progetto FITP eSports.
